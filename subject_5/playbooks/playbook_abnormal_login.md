# 플레이북: 비정상 로그인 대응 (PB-001)

## 1. 개요 및 메타데이터
- **플레이북 ID**: PB-001
- **분류**: 계정 탈취 의심 / Credential Stuffing
- **예상 소요 시간**: 자동 격리 1분, 승인 절차 포함 총 10분 이내
- **관련 규정/컴플라이언스**: ISMS-P 인증기준 2.6 접근통제

## 2. 트리거 (Trigger)
- SIEM/IdP 로그 상 5분 이내 동일 계정에 대한 10회 이상 로그인 실패 후 해외 미인가 IP에서의 로그인 성공 이벤트 발생
- 불가능한 이동 속도(Impossible Travel) 탐지 경보 발생 시

## 3. 조건 (Condition)
- 탐지된 사용자 계정이 `config/vip_accounts.json`에 포함되어 있는지 검사
- 로그인 출발지 IP가 위협 인텔리전스(TI) 위험 IP 리스트에 등재되어 있는지 여부

## 4. 대응 액션 (Actions) 및 흐름
1. **[자동] 세션 종료 (`terminate_session`)**:
   - 위험도: Low
   - 승인 불필요: 즉시 해당 계정의 모든 활성 세션 토큰 폐기.
2. **[승인 게이트] 계정 잠금 (`lock_account`)**:
   - 위험도: Critical
   - **승인 필요**: 일반 계정일 경우 SOC 분석가 승인 후 잠금, 대상이 VIP 계정인 경우 CISO 또는 보안팀장의 추가 확인 필요.
3. **[승인 게이트] 침해 IP 차단 (`block_ip`)**:
   - 위험도: High
   - **승인 필요**: 해당 IP가 클라우드 프록시 또는 NAT IP인지 확인 후 방화벽 차단 승인.
4. **[자동] 티켓 생성 및 알림**:
   - ITSM 티켓 발급 및 담당 분석가 슬랙 채널 전파.

## 5. 승인자 (Approver)
- 일반 계정 조치: SOC 1차/2차 분석가
- VIP 계정 조치: CISO 또는 정보보호팀장

## 6. 오탐 시나리오 대응
- 해외 출장자의 정상 VPN 로그인 또는 오탐으로 판명될 경우, 즉시 계정 잠금 해제(`unlock_account`) 및 IP 차단 해제(`unblock_ip`) 수행 후 4과목 학습셋에 라벨 추가.
