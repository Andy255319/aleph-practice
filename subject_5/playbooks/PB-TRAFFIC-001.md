# 보안 대응 플레이북: 트래픽 급증 (PB-TRAFFIC-001)

| 항목 | 작성 내용 |
|---|---|
| **플레이북 ID** | **PB-TRAFFIC-001** |
| **플레이북 이름** | 트래픽 급증 및 DDoS 의심 대응 절차 |
| **트리거 (Trigger)** | 현재 트래픽이 기준선(Baseline)보다 급격히 증가함 |
| **조건 (Condition)** | 정상적인 트래픽 증가인지, 특정 출발지의 집중 요청인지 확인 |
| **액션 (Action)** | 1. 트래픽 분석<br>2. 운영 담당자 알림<br>3. 제한 조치(Rate Limit/IP 차단) 검토 |
| **승인자 (Approver)** | 인프라 운영 담당자 및 네트워크 보안팀장 |
| **예상 소요 시간** | 3분 (승인 대기시간 제외) |
