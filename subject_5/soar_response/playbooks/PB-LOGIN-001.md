# 보안 대응 플레이북: 비정상 로그인 (PB-LOGIN-001)

| 항목 | 작성 내용 |
|---|---|
| **플레이북 ID** | **PB-LOGIN-001** |
| **플레이북 이름** | 비정상 로그인 대응 절차 |
| **트리거 (Trigger)** | 로그인 실패가 짧은 시간에 반복 발생하고 이후 로그인 성공이 확인됨 |
| **조건 (Condition)** | 동일 사용자·IP·시간대의 연관성을 확인하고 위험도를 평가 |
| **액션 (Action)** | 1. 관련 로그 수집<br>2. 담당자 알림<br>3. 계정 잠금 검토 및 차단 실행 |
| **승인자 (Approver)** | 보안 담당자 (Security Analyst / Security Manager) |
| **예상 소요 시간** | 5분 (승인 대기시간 제외) |

---

## 세부 대응 흐름 및 승인 단계
1. **[탐지 및 로그 수집]**: 동일 사용자 계정의 인증 실패 로그(Event ID 4625 등) 및 성공 로그(4624) 수집.
2. **[담당자 알림]**: Slack 관제 채널 및 이메일로 1차 경보 발송.
3. **[승인 게이트 (필수)]**: 계정 잠금(`lock_account`)은 일반 업무 차단 리스크가 있으므로 반드시 **보안 담당자의 사전 승인 후 실행**.
4. **[격리 조치]**: 승인 확인 즉시 활성 세션 종료(`terminate_session`) 및 계정 비활성화.
