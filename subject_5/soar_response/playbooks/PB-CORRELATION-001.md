# 보안 대응 플레이북: 상관분석 매칭 (PB-CORRELATION-001)

| 항목 | 작성 내용 |
|---|---|
| **플레이북 ID** | **PB-CORRELATION-001** |
| **플레이북 이름** | 다단계 상관분석 복합 침해 대응 절차 |
| **트리거 (Trigger)** | 로그인 실패 급증 $\rightarrow$ 로그인 성공 $\rightarrow$ 비인가 접근의 연관 패턴 탐지 |
| **조건 (Condition)** | 사용자, IP, 시간 순서 및 접근 권한을 확인 |
| **액션 (Action)** | 1. 관련 이벤트 통합<br>2. 위험도 평가<br>3. 담당자 알림<br>4. 계정 조치 검토 |
| **승인자 (Approver)** | 침해대응반(CERT) 팀장 및 CISO |
| **예상 소요 시간** | 10분 (승인 대기시간 제외) |

---

## 세부 대응 흐름 및 승인 단계
1. **[이벤트 통합 및 위험도 평가]**: 인증, 접근 통제, SaaS 감사 로그를 시간 윈도우 기반으로 상관분석.
2. **[담당자 긴급 알림]**: P1 최고 위험도 침해사고 긴급 소집 알림 전파.
3. **[승인 게이트 (필수)]**: 계정 비활성화 등 영향이 큰 조치는 **보안 관리자/CISO 승인 후 실행**.
4. **[격리 조치]**: C2 악성 IP 차단 및 감염 호스트 네트워크 격리, 탈취 자격증명 리셋.
